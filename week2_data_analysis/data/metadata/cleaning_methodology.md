# Cleaning Methodology

The raw data generated by the OpenFDA API (or fallback mechanism) requires preprocessing before statistical testing. The steps are implemented in `data_cleaning.py`.

## Steps Performed
1. **Deduplication:** Checks for and removes exact duplicate rows to prevent double-counting.
2. **Missing Values:** Identifies missing or NaN values in counts and replaces them with 0 (assuming null indicates no reports were found for that query).
3. **Type Validation:** Ensures `total_reports` and `adr_count` are standard integers.
4. **Feature Engineering:** Calculates the `non_adr_count` variable (`total_reports` - `adr_count`). This is structurally necessary to quickly populate the cells of a 2x2 contingency table (cells b and d) for disproportionality analysis.
5. **Standardization:** Formats text fields (e.g., converting `adr_term` to Title Case for cleaner plot labels).

## Output
- The output is saved to `processed_faers_data.csv`.
- A log file `cleaning_report.txt` is generated recording the exact number of modifications made during the cleaning pipeline.
